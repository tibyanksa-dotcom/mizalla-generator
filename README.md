# مِظلة — المولد المستقل

[افتح المولد المجاني](https://tibyanksa-dotcom.github.io/mizalla-generator/)

مولد عربي يعمل داخل المتصفح، يستخدم القوالب الستة الأصلية لمِظلة بخط Tajawal وترتيب أقسامها: أثر، نبض، ميدان، رفد، شفافية، وعطاء.

- معاينة للكمبيوتر والجوال، وتحرير الأقسام والبطاقات مع حفظ المسودة محليًا.
- ينتج حزمة فيها موقع عام ولوحة إدارة مستقلة وإعداد قاعدة خاصة.
- لا يحتاج تشغيل المولد حساب Teable أو ذكاء اصطناعي أو خادم توليد.
- لا يحتوي هذا المستودع بيانات جهات أو مفاتيح حسابات. بيانات النماذج لا ترسل إلى المستودع.
- إعداد قاعدة البيانات ونشر موقعي العميل خطوتان منفصلتان موضحتان في الحزمة الناتجة.

المصدر الكامل وملفات التشغيل والخطوط والتراخيص موجودة داخل `site/`. بعد استيراد المصدر الأول، يستخدم النشر ملفات المستودع نفسه. راجع [دليل المولد](site/README.md).
