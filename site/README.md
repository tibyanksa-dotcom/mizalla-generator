# مِظلة — المولد المستقل

موقع ثابت عربي يعمل داخل المتصفح لإنشاء حزمة موقع عام ولوحة إدارة منفصلة من ستة قوالب. لا يحتاج تشغيله حساب Teable أو نموذج ذكاء اصطناعي أو خادم توليد.

## الاستخدام

افتح الموقع، أدخل هوية الجهة وبريد المدير، واختر القالب وحرر أقسامه. راجع المحتوى ثم اعتمد التوليد لتنزيل ZIP. يمكن استيراد ملف مواصفات بصيغة mizalla-portable-v1، أو استلام المواصفات المعتمدة من مصنع مِظلة عبر رسالة متصفح محددة المصدر.

بيانات النماذج تحفظ في متصفح المستخدم فقط ولا تضاف إلى المستودع أو ترسل إلى خادم توليد. استخدم «مسح المسودة المحلية» عند الانتهاء على جهاز مشترك. المفاتيح السرية مرفوضة؛ إعداد Supabase يقبل مفتاح publishable أو anon العام فقط.

## الملفات الناتجة

- public-site: الموقع العام بمحتوى الجهة المعتمد.
- admin-site: تطبيق مستقل لإدارة المحتوى والعمل التطوعي والمستندات والمستخدمين.
- private-setup: مخطط قاعدة Supabase وسياسات RLS والمواصفات الخاصة. لا تنشر هذا المجلد.
- README-AR.md: خطوات الإعداد والنشر.

المولد ينتج ملفات، ولا يدعي أن موقع العميل نُشر أو أن قاعدة بيانات أُنشئت. لوحة الإدارة تحتاج مشروع Supabase مستقلاً للجهة. يتضمن المخطط أدوار مدير ومحرر ومسؤول تطوع ومراجع، ويمنع عرض الملفات إلا بعد الاعتماد وإذن العرض معاً. خدمات الاستضافة وقواعد البيانات الخارجية تعمل ضمن خططها وحدودها.

## الاستضافة

هذه الملفات قابلة للنشر مباشرة على GitHub Pages أو أي استضافة مواقع ثابتة. لا توجد خطوة بناء لازمة لتشغيل النسخة الموزعة. جميع ملفات التنفيذ والخطوط موجودة محلياً داخل المجلد. ملف workflow الخاص بالاستيراد الأول ينقل المصدر مرة واحدة إلى المستودع، وبعد ذلك يعتمد النشر على ملفات المستودع نفسه.
